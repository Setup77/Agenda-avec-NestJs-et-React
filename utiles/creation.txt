1. Architecture cible (vision globale)

Avant d’installer quoi que ce soit, il est important de comprendre ce que nous allons construire.

Stack technique retenue

Backend API : NestJS (Node.js moderne, structuré, sécurisé)

Base de données : MongoDB

Frontend : HTML / JS (ou plus tard React/Vue si souhaité)

Agenda : FullCalendar (plugin JS)

Authentification : JWT (plus tard)

Serveur local :

Node.js pour le backend

WAMP uniquement si vous avez déjà des projets PHP (non obligatoire pour NestJS)


3. Installation des outils indispensables
3.1 Installer NestJS CLI (outil principal)

NestJS se crée via une CLI officielle.

npm install -g @nestjs/cli


Vérification :

nest --version



3.3 Vérifier MongoDB (serveur)

MongoDB Compass est installé, mais il faut s’assurer que le serveur MongoDB tourne.

Dans Compass :

URI :

mongodb://localhost:27017

4. Création du projet backend NestJS

Nous allons maintenant créer le serveur API.

Dans un dossier de travail (ex : C:\projects) :

nest new agenda-backend

cd agenda-backend
npm run start:dev
